# SandboxOS — Brand Assets

Exported static marks (SVG) for use where React components aren't available.

- `wordmark.svg` — the SANDBOXOS lockup (▚ + magenta OS)
- `mark.svg` — the ▚ icon mark (favicon / app icon)
- `sticker-seal.svg` · `sticker-hazard.svg` · `sticker-burst.svg` — die-cut sticker marks
- `barcode.svg` — provenance strip
- `arabic-seal.svg` — the rare Arabic calligraphic maker's-mark (حُرّ — "free")

The **character** is generated at runtime by the dither engine (`character-v2.html`), not a static file — drop licensed/CC0 reference art through that pipeline for higher fidelity. Fonts referenced by these SVGs ship via `styles.css`.
