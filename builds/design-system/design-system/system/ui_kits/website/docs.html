401 · quickstart · ~3 min

Run it yourself

install the machine, mount your first cartridge, build a thing. no permission slip required.

01 · install

one line. it runs local — on your own machine, and that's half the fun. no cloud in the loop.

$ curl sandbox.os/install | sh
# warming up the workbench… memory: the bugs you beat, kept… ready.

02 · mount a cartridge

a cartridge is a shareable, plug-n-play build. download one, slot it, run it. fork it and it's yours — serial, edition, © nobody.

$ sbx mount career-ops --serial 001/500
$ sbx run

03 · build

tell it what you're making. it remembers, it heckles your worst ideas before you ship them, it keeps the bugs you beat. it is not an assistant — it's the thing you built.
