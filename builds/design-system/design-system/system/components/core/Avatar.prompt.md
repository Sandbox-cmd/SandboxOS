A die-cut frame holding the character (a kaomoji mood) or initials, with an optional status dot + serial. Use for user/agent identity.

```jsx
<Avatar face="⌐■_■" status="online" serial="982-V7" />
<Avatar initials="SBX" status="rebel" />
```

Props: face · initials · size · status (online|building|away|rebel) · serial.
