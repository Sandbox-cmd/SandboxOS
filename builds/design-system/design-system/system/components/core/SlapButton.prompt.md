The SandboxOS button — a die-cut sticker slap that presses DOWN like a real slap. Use for every action; mono by default, color earned via `tone`.

```jsx
<SlapButton tone="go" size="lg">↓ install</SlapButton>
<SlapButton tone="ghost">later</SlapButton>
<SlapButton tone="rebel" rotate={-6}>nobody's tool</SlapButton>
```

Tones: default · ghost · go (amber) · rebel (magenta) · ok (green) · danger. Sizes sm/md/lg. `rotate` for hand-stuck tilt.
