The die-cut sticker system — usable as UI (callouts, awards, buttons) AND decoration. Plus a procedural Barcode provenance mark.

```jsx
<Sticker shape="seal" tone="rebel" rotate={-6}>no bad vibes</Sticker>
<Sticker shape="ribbon" tone="alert">limited run</Sticker>
<Sticker shape="price" tone="hazard">$0.00</Sticker>
<Barcode seed="982V7" />
```

Shapes: tag · pill · seal · burst · ribbon · price · stamp · callout. Tones: hazard · alert · rebel · go · cyan · ink · paper · striped.
