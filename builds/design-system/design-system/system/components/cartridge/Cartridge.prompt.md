The build object as a rotating 3D plug-n-play module — the one place the flat UI breaks into dimension (dimension = ownership). Use for builds, packs, shelves.

```jsx
<Cartridge title={"Career\nOps"} kind="build" serial="001/500" width={184} />
```

kind color-codes the spine: build (supercolor) · skill (cyan) · persona (magenta). `spin` auto-rotates (hover speeds up).
