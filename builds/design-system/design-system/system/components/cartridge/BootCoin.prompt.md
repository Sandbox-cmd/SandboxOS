A minted 3D coin — the boot token, scar-coin, or achievement reward. Dimension = ownership, so reserve it for owned/minted moments (boot key, milestones, celebrated errors).

```jsx
<BootCoin label="SBX" serial="982-V7" tone="amber" />
<BootCoin label="SCAR" glyph="☠" tone="rebel" serial="ERR-404" />
```

Props: size · label · serial · glyph · tone (amber|rebel|green|cyan) · spin (hover speeds up).
