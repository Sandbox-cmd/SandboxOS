# design-system

"**SandboxOS — a bootleg OS for makers.**" The production design system. Hameed had been
building **Bootleg OS** directly on claude.ai/design, outside the canon; 2026-06-20 took it
through the SandboxOS frame into a v2 production kit, applied it to launch surfaces, and
shipped. Replaces the scrapped SITE ARC design work; distinct from `[[sandbox-site]]` — the
site is the *marketing surface*, this is the *language it is built from*.

## The frame (owner-locked — the load-bearing decisions)
A deep dive fed GATE 2; Hameed overrode three of its recommendations on taste/vision. The
override is the amana — a deep dive is input to the gate, never the verdict. Full record:
`first-remote-publish` sibling decision `[[loud-bootleg-foundation-lock]]`,
`studio/2026-06-20-ds-deepdive/frame-lock.md`.

- **Bootleg OS is the soul** — base AND dominant register. NOT GHOSTLINE (owner dislikes it).
- **Playful/loud is the foundation premise at every level**, not a where-earned tier (overrode
  the deep dive's surface-tiering rec).
- **"Living Gradient Schematic" is out** (owner: cringe). **New category** — the owned machine +
  the workbench act (NOTICE · BUILD · SHIP). Product name unchanged.
- **v2 = reinvent, don't copy** — keep the strong foundation (tokens/engines), rebuild the rest.
- **License PARKED** — pricing built on the FSL + founding-deployments lean, marked swappable.
- **Voice** — "NOTICE. BUILD. RELEASE." spine; loud chrome, civilian words, memory = one RTB line.
- Register-neutral blockers (form a11y, dense primitives, no Google-CDN fonts, civilian-legible
  public copy) survive "loud everywhere" — NOT softened by it.
