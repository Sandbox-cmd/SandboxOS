# The three faces

The pages are set in three faces, each under the SIL Open Font License, version 1.1:

- **Bricolage Grotesque**: titles, part labels and sentences.
- **IBM Plex Mono**: times, dates, identifiers and key caps.
- **IBM Plex Sans Arabic**: the Arabic column, and a mono label word when the page reads in Arabic.

They are here as `.woff2` files, each family's licence beside them, named by family and weight
(`BricolageGrotesque-Variable.woff2`, `IBMPlexMono-Regular.woff2`, `IBMPlexMono-Medium.woff2`,
`IBMPlexMono-SemiBold.woff2`, `IBMPlexSansArabic-Regular.woff2`, `IBMPlexSansArabic-Medium.woff2`,
`IBMPlexSansArabic-SemiBold.woff2`, `IBMPlexSansArabic-Bold.woff2`; the licences `BricolageGrotesque-OFL.txt`,
`IBMPlexMono-OFL.txt`, `IBMPlexSansArabic-OFL.txt`). The pages declare an `@font-face` for each file that is here,
copy the files beside every written view, and serve them at `/fonts/`; nothing loads a face from any address.

On 2026-10-31 none of the three was on this machine and the night fetched nothing (morning card 6). On the maker's yes
to that card, builder C (claude-opus-5-5) fetched them on 2026-11-02 from their makers' public addresses on GitHub;
`SOURCES.md` names each file's address, its bytes and its sha256. The folder is exempt by name from the "no other
grant" check (DECISIONS row 94) and is measured apart from the pages' line budget.
